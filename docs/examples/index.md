# Examples

Worked, solved examples built on the public flex-pse API live in the
companion repository
[flex-pse-examples](https://github.com/flex-pse/flex-pse-examples), published
as an interactive site at
[flex-pse.github.io/flex-pse-examples](https://flex-pse.github.io/flex-pse-examples/).
Each example opens directly in a browser — no installation, no solver setup —
and shows a real flowsheet, a solved schedule, and the tariff or dispatch
signal that shaped it.

That site is a separate, independently versioned project so its examples can
be added to and updated without going through this repository's release
cadence. See [Build a plant](../how_to/build_a_plant.md) and
[Parameterize a model from data](../how_to/parameterize_from_data.md) for the
API those examples are built on.
